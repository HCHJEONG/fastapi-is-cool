# Design Notes

The visual direction for this project and its related applications is based on
neo-brutalism.

## Core Style

- Use bold, direct layouts with clear hierarchy.
- Prefer high-contrast surfaces, strong borders, and visible structure.
- Use flat color blocks rather than soft glassmorphism or atmospheric gradients.
- Keep interactions obvious, tactile, and slightly playful.
- Favor clarity and confidence over polish that feels generic.

## UI Principles

- Buttons and controls should feel concrete and easy to identify.
- Important panels can use thick borders, offset shadows, or hard-edged
  elevation.
- Typography should be legible, assertive, and restrained.
- Avoid overly rounded, overly soft, or overly decorative components.
- Keep spacing intentional; dense screens should still be scannable.

## Shared App Consistency

The sibling applications should feel related, even when they solve different
problems:

- `global-ai-pricing`
- `legacy-lang-intelligence`
- `semantic-layer-explore`

Use the same broad design language across these apps where practical:

- strong outlines
- crisp section boundaries
- simple color systems
- direct labels
- functional controls
- minimal decorative noise

## Backend Admin Or Internal UI

If this backend gains an admin page, dashboard, docs skin, or internal tool:

- keep it work-focused and compact
- use neo-brutalist accents without sacrificing readability
- prioritize operational clarity over marketing-style presentation
- make service state, errors, configuration, and health checks easy to scan
